What is {{ request.site.name }}?

{{ request.site.name }} is an open-source feature board web app. You can propose features and vote on them.

There's one twist, though: Twice a day, at noon and midnight UTC, the top-voted feature is automatically implemented on {{ request.site.name }}. The site vibe-codes itself.

What will you make of {{ request.site.name }}? There's only one way to find out.

How it works

  • Click the floating button on the right and submit a feature request for something you want to see changed on this site.
  • Vote on feature requests.
  • Twice daily (noon and midnight UTC), the top-rated feature request will be automatically implemented by AI and deployed to this site.
  • All votes reset after each implementation window.

Beware the Feature Graveyard

Ideas that wander the board for more than a week without being implemented fade into the graveyard. You can pay your respects and see what haunts the backlog from the board’s new graveyard view.

Keep your favorites alive: rally votes before midnight on the seventh day, or they’ll return draped in spectral CSS.
